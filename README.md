# EcoTrack API

## Objetivo

Sistema ESG para gestão sustentável de resíduos com monitoramento de lixeiras, alertas automáticos, coletas e indicadores.

## Tecnologias

- Java 21
- Spring Boot
- Oracle Database
- Flyway
- Spring Security
- Docker
- Maven

## Funcionalidades

### Lixeiras
- Cadastro
- Atualização
- Monitoramento de ocupação

### Localizações
- Gestão de pontos de descarte

### Coletas
- Registro automático
- Atualização do nível da lixeira

### Alertas ESG
- Geração automática
- Resolução de alertas

### Indicadores ESG
- Total de lixeiras
- Alertas pendentes
- Coletas realizadas
- Ocupação

## Segurança

- Spring Security
- Basic Authentication

## Como executar

```bash
mvn clean package
```

```bash
docker compose up
```
